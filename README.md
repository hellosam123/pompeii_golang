# Pompeii Golang

A Golang port of Pompeii. Pompeii is a Vocabulary tester web app created by G10 ISF students Samuel Lam and Mia Wong.

## Information

### Supported Vocab Lists

- Latin IGCSE
- Latin GCSE DVL
- Spanish Ab Initio - Ropa
- Spanish Ab Initio - Atributos Personales
- Spanish Ab Initio - Vocabulary Foto
  
In the future, other vocab lists from different languages may be integrated.
